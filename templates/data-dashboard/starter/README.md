# Data Dashboard Starter

This starter is copied into the output workspace before the generation phase runs.

Commands:

1. Copy `.env.example` to `.env`
2. Run `pnpm install`
3. Run `pnpm typecheck`
4. Run `pnpm dev`

The starter is frontend-only. It intentionally does not include Prisma, database scripts, authentication scaffolding, or backend route handlers.
