# 工业大屏深色主题 design.md

> 适用范围：用于指导 LLM / 设计工具 / 前端开发生成 **工业大屏、工厂驾驶舱、运营指挥中心、设备监控大屏、能源管理大屏** 等深色主题界面。
> 核心目标：生成一个 **16:9、深色、专业、工业科技感、可交付开发** 的大屏 UI，而不是浏览器截图、显示器样机图或普通后台管理页面。

---

## 0. 最高优先级规则

### 0.1 必须遵守

- 只输出 **工业大屏 UI 本身**。
- 使用 **16:9 横屏画布**。
- 默认尺寸：`1920 × 1080`。
- 整体必须为 **深色主题**。
- 页面需要具备 **工业运营指挥中心** 气质。
- 信息组织必须围绕：
  - 全局状态
  - 核心 KPI
  - 生产执行
  - 设备健康
  - 能耗趋势
  - 质量监控
  - 实时告警
  - AI 优化建议
- 页面应像一个成熟工业互联网平台的大屏驾驶舱，而不是普通网页后台。

### 0.2 禁止出现

生成设计稿时，禁止出现以下元素：

- 显示器外框
- 电脑屏幕样机
- 浏览器地址栏
- 浏览器标签页
- Windows / macOS 窗口边框
- 手机 / 平板外框
- 鼠标指针
- 网页滚动条
- 右侧全局滚动条
- 外层展示底板
- 过度赛博朋克风格
- 过量霓虹光效
- Excel 表格截图风格
- 普通后台管理系统风格

### 0.3 一句话约束

```text
Only the industrial dashboard UI. Dark theme. 16:9. No monitor mockup. No browser chrome. No scrollbar.
```

## 1. 设计定位

### 1.1 风格关键词

```text
Industrial
Dark Theme
Command Center
Data Cockpit
Factory Dashboard
Real-time Monitoring
Professional
Technological
Structured
High Readability
Calm but Powerful
```

### 1.2 设计气质

工业大屏应该体现：

- 专业稳定
- 工业可信
- 数据清晰
- 实时监控感
- 指挥调度感
- 科技感克制
- 可远距离阅读

不应该体现：

- 炫技海报感
- 游戏 HUD 感
- 赛博朋克泛滥
- 装饰大于数据
- 过度 3D 拟物
- 信息堆砌混乱

### 3.1 基础颜色

```text
Background Base: #08111F

Primary Text: #EAF3FF
Secondary Text: #9DB3CC
Tertiary Text: #6E829B
Disabled Text: #465A72

Primary Blue: #2F80FF
Cyan Accent: #28D7FF
Teal Accent: #18C8C1
Green Good: #2ED47A
Yellow Warning: #F5C94A
Orange Alert: #FF9F43
Red Critical: #FF5A5F
Purple AI: #7B61FF
```

### 3.2 背景建议

```css
background:
  radial-gradient(circle at 50% 0%, rgba(47, 128, 255, 0.14), transparent 34%),
  radial-gradient(circle at 12% 88%, rgba(40, 215, 255, 0.08), transparent 28%),
  linear-gradient(180deg, #091321 0%, #08111F 55%, #050B14 100%);
```

### 3.3 色彩使用规则

- 蓝色：主信息、核心指标、主趋势线。
- 青色：实时数据、流动线、科技高亮。
- 绿色：正常、运行中、达标、健康。
- 黄色：一般预警、注意、待确认。
- 橙色：重要预警、偏差、风险升高。
- 红色：严重告警、故障、停机。
- 紫色：AI 分析、智能建议、预测能力。
- 不要让红色、黄色占比过高，否则页面会显得失控。
- 不要把所有模块都做成高亮发光。

## 4. 字体规范

### 4.1 字体族

```css
font-family:
  "DIN Alternate",
  "DIN",
  "Inter",
  "Alibaba PuHuiTi",
  "PingFang SC",
  "Microsoft YaHei",
  sans-serif;
```

### 4.2 字号层级

```text
大屏标题：32–40px / 700
一级模块标题：18–22px / 600
二级标题：15–17px / 500–600
核心 KPI 数字：42–72px / 700–800
普通 KPI 数字：28–40px / 700
正文：14–16px / 400–500
表头：13–14px / 500–600
辅助说明：12–13px / 400
小标签：11–12px / 400
```

### 4.3 字体规则

- 核心数字必须足够大。
- 中文标题要稳重，不要过细。
- 单位字号应小于数字。
- 辅助说明使用灰蓝色，不与主数据抢层级。
- 不要把所有文字都加粗。
- 大屏要考虑远距离可读性，避免大量 10px 以下文字。

## 5. 布局系统

### 5.1 推荐栅格

```text
24-column grid
Outer Margin: 24px
Gutter: 16–24px
Panel Radius: 12–16px
```

### 5.2 典型布局比例

```text
Left Column: 23–25%
Center Column: 50–54%
Right Column: 23–25%
```

### 5.3 信息密度

工业大屏允许信息丰富，但必须分层：

- 第一层：顶部标题和系统状态
- 第二层：核心 KPI
- 第三层：中央工厂总览 / 主趋势
- 第四层：左右辅助模块
- 第五层：底部事件、待办、明细

不要把所有信息放在同一视觉强度上。

## 6. 面板规范

### 6.1 面板样式

```css
.panel {
  background: linear-gradient(
    180deg,
    rgba(18, 38, 62, 0.96),
    rgba(12, 27, 45, 0.92)
  );
  border: 1px solid rgba(79, 140, 255, 0.24);
  border-radius: 14px;
  box-shadow:
    0 10px 30px rgba(0, 0, 0, 0.28),
    inset 0 1px 0 rgba(140, 196, 255, 0.08);
}
```

### 6.2 面板标题

```text
左侧：模块图标 + 模块标题
右侧：可选操作，如 更多、详情、箭头
```

标题规则：

- 图标尺寸：16–20px。
- 标题字号：18–22px。
- 标题颜色：#EAF3FF。
- 可使用细蓝线或角标增强科技感。
- 不要使用厚重装饰边框。

### 6.3 面板边框

允许：

- 轻微蓝色描边
- 顶部细发光线
- 角落短线装饰
- 内发光

禁止：

- 厚重实线边框
- 强烈霓虹外发光
- 每个面板都过度装饰

## 7. KPI 卡片规范

### 7.1 KPI 卡片结构

```text
[Icon] [Label]
       [Large Number] [Unit]
       [Delta / Status]
```

### 7.2 常用 KPI

```text
今日产量：12,680 吨
OEE：86.4%
设备在线率：97.2%
综合能耗：3,420 kWh
告警总数：18
合格率：98.7%
停机时长：42 min
计划达成率：94.0%
```

### 7.3 KPI 设计规则

- 一屏顶部建议 4–6 个 KPI。
- 图标作为辅助，数字才是主体。
- 数字颜色可以根据状态变化。
- 告警类 KPI 使用红色，但面积要克制。
- 正常类 KPI 使用绿色或蓝色。
- KPI 卡片高度保持一致。

## 8. 图表规范

### 8.1 折线图

适合：

- 产量趋势
- 能耗趋势
- 温度趋势
- 设备负载趋势
- OEE 变化趋势

规则：

- 背景网格线使用低透明度。
- 折线最多 3 条。
- 主线蓝色，辅线青色。
- 关键异常点可用红 / 橙标记。
- 坐标轴文字要清晰但不抢视觉。

### 8.2 柱状图

适合：

- 产线产量对比
- 班组效率排行
- 缺陷数量排行
- 能耗分项对比

规则：

- 柱体使用蓝色或青色渐变。
- 排名类图表建议横向柱状图。
- 最高值可高亮。
- 不要使用过多颜色。

### 8.3 环形图

适合：

- 质量缺陷占比
- 设备状态占比
- 工单状态占比
- 能源结构占比

规则：

- 中心可以显示总值或关键比例。
- 图例必须简洁。
- 色彩不超过 5 类。
- 不要把环形图做得过于花哨。

### 8.4 状态列表

适合：

- 设备健康
- 实时告警
- 待处理事项
- 工单进度

规则：

- 使用状态点表达状态。
- 严重告警使用红色。
- 重要告警使用橙色。
- 一般预警使用黄色。
- 正常运行使用绿色。
- 列表行数建议 5–8 行。

## 9. 中央工厂总览规范

### 9.1 中央视觉焦点

大屏中间区域应作为视觉中心，可使用：

- 工厂平面示意图
- 产线拓扑图
- 工艺流程图
- 设备连接图
- 区域态势图
- 能流 / 物流 / 数据流示意

### 9.2 表现方式

推荐：

- 简化建筑块
- 线框式厂区图
- 轻 3D 俯视感
- 发光连线
- 状态点
- 区域标签

不推荐：

- 拟真照片
- 复杂三维渲染
- 真实地图截图
- 大量无意义装饰

### 9.3 状态表达

```text
绿色：运行中
蓝色：待机
灰色：停机
红色：告警
黄色：预警
```

## 10. 告警模块规范

### 10.1 告警字段

```text
时间 | 级别 | 告警内容 | 位置 | 状态
```

### 10.2 告警等级

```text
严重：红色
重要：橙色
一般：黄色
提示：蓝色
```

### 10.3 告警设计规则

- 严重告警必须醒目。
- 告警模块不宜过大，避免压迫全屏。
- 最新告警放在最上方。
- 可使用小圆点、标签、细线区分等级。
- 不要使用大面积红色背景。

---

## 11. AI 优化建议模块

### 11.1 模块定位

AI 建议模块用于表达智能化能力，而不是普通提示栏。

可包含：

- 能耗优化建议
- 设备维护预测
- 生产调度建议
- 质量异常预测
- 工艺参数优化
- 风险预警摘要

### 11.2 设计风格

- 可使用蓝紫色作为辅助强调。
- 卡片比普通告警更轻。
- 建议内容应简洁，避免长段文字。
- 可以使用“预计节能”“风险降低”“预估增产”等结果标签。

## 12. 底部事件时间轴

### 12.1 适用场景

- 生产节奏记录
- 关键事件回放
- 班次节点
- 告警处理过程
- 调度时间线

### 12.2 时间轴结构

```text
08:00 班前点检完成
09:15 原料到厂
10:40 工艺切换完成
12:20 温度预警
14:05 设备振动报警
14:30 当前时间
```

### 12.3 设计规则

- 使用横向时间轴。
- 节点颜色表达状态。
- 当前时间节点可使用蓝色高亮。
- 异常节点可使用黄色 / 红色。
- 时间轴不宜过高，作为底部辅助信息。

---

## 13. 组件规范

### 13.1 图标

- 使用线性或轻面性图标。
- 描边统一。
- 工业图标可包括：工厂、设备、闪电、告警、图表、盾牌、机器人、齿轮。
- 图标不要比数字更抢眼。

### 13.2 标签

```text
运行中：绿色
待机：蓝色
停机：灰色
告警：红色
预警：黄色
```

### 13.3 进度条

- 背景：深蓝灰。
- 前景：蓝色 / 青色。
- 达标：绿色。
- 风险：黄色或橙色。
- 异常：红色。

### 13.4 表格

- 不要做成传统 Excel 表格。
- 行高建议 30–40px。
- 表头弱化。
- 状态字段使用颜色点或标签。
- 斑马纹可极淡，不要明显。
